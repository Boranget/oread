## 一、已确定不做（勿再排期）

- 音频 / 视频 / 音乐 / 游戏 / 正版音频内容。
- RSS、用户侧备份与恢复（WebDAV）、词典与翻译。
- 平台原生特性（通知栏、桌面组件、音量键等）、边角页面、本地书籍导入。
- WebView / `java.webView*` 桥、人机验证绕过、客户端签名算法。

## 二、当前优先

3. KPW3 真机回归：文字书与漫画各走一遍离线阅读（设备网络恢复后）。

   `chapter_url → book_url` 反查三个问题。
6. 管理员编辑 v2：章节增删、拆分、合并，漫画页数量调整（v1 明确不做）。
7. 从书源详情页自动映射系列名、系列序号、标签。
8. EPUB 补内联正文图片、封面、脚注。

10. 补 README / CHANGELOG，把“目录即书”和旧缓存表已删写清楚。

## 三、已知缺口

### P1

- `GET /api/book/info` 会覆盖用户在 `book_meta` 的 `group` / `custom_*` / `can_update`；
  更新语句应改为 `COALESCE(excluded.x, 现有值)`。
- 前端入口缺失：书源校验/检查更新、规则导入导出/试跑、用户管理、书架批量操作。
  后端能力已存在，但页面上点不到。

### P2

- 正文 HTML/图片渲染口径未定：纯文本还是受控 HTML；漫画阅读依赖这个结论。
- 缓存键不含书源 `origin`，不同书源共用同一 URL 时可能串目录/正文。
- 书源保存是整份 JSON 覆盖，没有并发保护；多人同时编辑会后写覆盖前写。

### P3

- `GET /api/bookshelf` 的 `book_id` 参数被忽略，始终返回全量书架。
- 首次启动偶发 SQLite `disk I/O error (4618)`，清理 WAL/SHM 后恢复，根因未复现。
- musl 产物在 `AAAA=NXDOMAIN` 误答的 DNS 后面会把解析直接判失败；
  现象像“所有书源都连不上”，换网络即恢复。

### 观察项

- SPA 首屏 JS 守住 ≤90 kB；漫画模块继续按需加载。
- `opt-level` / `target-cpu` 暂不动，等有可复现的压测基准再说。

## 四、工程改进（可选）

## 五、环境事实（不是本项目 bug）

- 部分真实书源自身配置错误、已失效或触发风控；不因此改解析器。
- 多数站点校验 `Referer`，封面直链返回 403；前端用占位图。
- KPW3 的硬约束见 [KPW3.md](KPW3.md) 与 [EINK_STYLE.md](EINK_STYLE.md)。
