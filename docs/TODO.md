# Boranlib 待办（精简版）

> 只记录**尚未完成的工作**和**已经定下的决策**。接口字段看 [API.md](API.md)，代码与数据流看
> [ARCHITECTURE.md](ARCHITECTURE.md)，构建看 [BUILD.md](BUILD.md)，部署看 [DEPLOY.md](DEPLOY.md)。
>
> **部署策略**：不做旧设备数据迁移。上线或大版本升级时直接删除旧 `data/` 重新初始化，
> 不再为旧库保留兼容代码、迁移脚本或验证任务。

## 一、已确定不做（勿再排期）

- 音频 / 视频 / 音乐 / 游戏 / 正版音频内容。
- RSS、用户侧备份与恢复（WebDAV）、词典与翻译。
- 平台原生特性（通知栏、桌面组件、音量键等）、边角页面。
- WebView / `java.webView*` 桥、人机验证绕过、客户端签名算法。
- **可点击脚注 / 行内链接**：正文模型是块级的标题 / 段落 / 列表 / 代码 / 分隔线 / 图片 /
  表格 / 公式，不做行内锚点跳转；书源里的脚注标记与注释文本已按普通段落保留。要支持就得引入
  行内富文本，与「防注入、可预测分页、`/k` 复用」的取舍冲突。
- **书源编辑的服务端乐观锁**：书源由管理员单人维护；前端保存前会读回比对并二次确认，
  不做版本号 / 冲突接口。
- **移除 `library_chapters`**：目录与正文已以书目录为准，但该表仍承担章节级 `is_vip` /
  `is_pay`、`chapter_url → book_url` 反查与临时书 TOC 缓存；删表需要另建反查索引与付费标记
  存储，收益不足，保留。

## 三、已完成（保留记录，避免重复设计）

- 表格 / MathML / SVG 正文（P0/P1/P2）：新增 `Block::Table`（`caption` / 行 / 单元格
  `colspan` / `rowspan` / 表头）、`Block::Math { mathml, text }` 与 `Block::Divider`；
  只把多行多列、无图片的真表格转成 `Table`，单格公式包装表与 1 行 2 图版式表继续按段落 /
  图片走。固定版式 EPUB 的 `<svg><text><tspan>` 按 `transform` 与文档顺序还原行并分组为
  段落，`<svg><image>` 还原为图片块。Ruby 只保留底字（`rt` / `rp` 注音丢弃），`<hr>` 成为
  分隔块，`figure` / `figcaption` / `details` / `summary` 等补齐块边界。Web 阅读器用真
  `<table>`、`<hr>` 与浏览器 MathML 排版；`/k` 表格按行分页并重复表头、公式用回退文本、
  分隔线用文本行；EPUB / TXT 导出与搜索走同一套降级。真实书验收：`Sous le vent` 13 个 SVG
  页恢复 10 页文字 + 2 页图片（仅 1 页真空白），`诡秘之主` SVG 封面出图，`EPUB 3.0
  Specification` 识别 34 个表格块，线性代数 1264 个公式块且 505 个单格公式表未变成数据表，
  绘本版式表未变成数据表。导入清理也覆盖独立 `.svg` 文件（脚本 / 事件属性 / 远程资源）。

- 真实 EPUB 兼容性：解析 XML 前清理 UTF-8 BOM 与 `<!DOCTYPE>`（含单引号 PUBLIC/SYSTEM
  与内部子集）；非 UTF-8 的 XHTML / CSS（真实书里常见 Shift_JIS 注释）不再让整次导入失败；
  纯 SVG 封面 / 空页返回空正文而不是 404；详情页目录在 `library_chapters` 为空时回退书目录；
  排版过的 XHTML / MathML 不再按源码换行拆段。23 本真实 EPUB 验收：全部导入、正文失败 0、
  详情目录与 `/api/book/toc` 一致。

- 个人图书馆信息架构：一级导航固定为首页 / 图书馆 / 统计 / 我的，管理区只对管理员出现；
  「书架」并入图书馆，个人状态（想读 / 在读 / 已读）作为馆藏之上的覆盖层，不做归档状态。
  前端改为 hash 路由（`#/library`、`#/book?url=...`、`#/admin?tab=...`），书卡统一进详情页，
  阅读器仍为全屏 overlay。后端新增只读聚合 `GET /api/library/{catalog,book,facets,home}` 与
  `POST /api/bookshelf/status`；个人状态落独立表 `reading_status`，不改动馆藏落盘结构。

- 正文语义块（标题 / 段落 / 列表 / 代码块 / 图片 / 表格 / 公式）：服务端解析、章节 XHTML
  读写、`/api/book/content` 的 `blocks`、Web 阅读器按块渲染、`/k` 按行预算分页且插图单独
  成页。列表保留层级与有序/无序样式；代码块用 `<pre>` 保留换行与缩进，`/k` 单独成页；
  表格保留表头与合并单元格，`/k` 按行分页并重复表头；独立公式保留清理后的 MathML。
- 插图原图入目录：按内容哈希写入 `OEBPS/images/`，只收 JPEG / WebP；读路径改写成
  `oread-img://`，墨水屏转码只在读取时生成。
- 漫画阅读：单页 / 连续滚动切换、100%–300% 缩放、邻近页预取与 objectURL 回收。
- 馆藏列表：排序 / 分页改用 `index.db`（书名 / 作者），搜索覆盖书名、作者、系列、标签；
  索引不可用时回退 `library.db`。
- 元数据：EPUB 导出带书源封面；详情页自动映射系列、系列序号、标签（只补空缺）。
- 管理员编辑 v1：改正文段落、改元数据、换封面、换漫画单页；含图片块的章节暂不支持整章覆盖。
- calibre 式文件编辑：文字书的文件树、源码编辑、跨文件字面量/正则替换、语义块预览、
  `Check book` 校验；写入仍以书目录为唯一权威，OPF 只推进修订号不重建。
  `Check book` 还会检查目录一致性：spine 缺 nav 项、nav 项不在 spine、spine 重复引用、
  manifest 孤立 XHTML、章节来源 URL 重复。
- EPUB 导入 v1：管理员上传 DRM-free EPUB，流式落盘后解压到 `.import/<token>/`，以内容文件
  公共父目录为基准整体平移进 `OEBPS/`（保留章节 / CSS / 字体 / 图片原结构），OPF 改名为
  `content.opf` 并只重写 manifest href；注入 `book-url` / 修订号 / 章节标题，重新生成 nav。
  文件 SHA-256 → 正文指纹 → 书名+作者 三层查重，命中后可选覆盖 / 新增 / 取消；覆盖只限
  馆藏书，保留书架位置与 `collected_at`，修订号递增。表格 / 列表 / 公式按语义块读写。
- 馆藏体检 `boranlib doctor --check-books`：对 `collection/` 下所有文字书跑一次只读 Check book，
  汇总错误/警告与打不开的书目录；warning 不影响退出码。
- 前端入口：书源校验 / 检查更新、规则导入导出 / 试跑、用户管理、书架批量操作均已可用。
- 文档：README、CHANGELOG 与部署 / 构建 / 架构 / API 文档已收敛。

## 六、环境事实（不是本项目 bug）

- 部分真实书源自身配置错误、已失效或触发风控；不因此改解析器。
- 多数站点校验 `Referer`，封面直链返回 403；前端用占位图。
- 首次启动偶发 SQLite `disk I/O error (4618)`，清理 WAL/SHM 后恢复，根因未复现。
- musl 产物在 `AAAA=NXDOMAIN` 误答的 DNS 后面会把解析直接判失败；
  现象像“所有书源都连不上”，换网络即恢复。
- KPW3 的硬约束见 [KPW3.md](KPW3.md) 与 [EINK_STYLE.md](EINK_STYLE.md)。
